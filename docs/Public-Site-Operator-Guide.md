# Public site operator guide

Super Admin → **Site Settings** (`/super-admin/settings`).

## Public navigation visibility

Toggles hide header, footer, and utility-bar links without taking the page down. Direct URLs still work.

Href list includes Opportunity, Platform, Strategic Pillars, Sectors, Projects, Afronovation, Strategic Inquiries, FAQs, Investor Journey, National Profile, and Contact. Hiding Contact also lets you hide Strategic Inquiries separately so the partnership page does not leak from the footer.

## Announcements vs popups vs legacy flash banner

| Tool | Use |
|---|---|
| **Announcements** | Primary public-site messaging. Stack or rotate. |
| **Marketing popups** | One-time-per-session modal on public chrome only |
| **Flash banner (legacy)** | Do not use. If one is still enabled, disable it from Settings. |

## CMS — Phase 1 pages only

Editable from Settings:

- Home hero carousel (English only; French keeps its translated copy)
- About Afronovation intro
- FAQ entries

Not CMS-editable: Opportunity, Platform, Investor Journey, Legal, Zimbabwe Profile. Sector blurbs are edited under **Taxonomies → Sectors**.

## Cookies

The public cookie banner records essential consent only. There is no analytics toggle. Legal copy matches that.

## What operators should not tell trainees

- This is not a localStorage demo.
- There is no public "Platform Admin Console" link on About Afronovation.
- Footer copy is operational, not "Demo MVP."
